# shark-browser
名前がかっこいいだけのただのブラウザです。オフラインでの利用も可能です。安全性は高めだと思います。claudeを使ってい開発をしています。
基本的な機能はすべて揃っています。
・キャッシュ
・ブックマーク
・履歴
・設定
・お気に入り機能
・右クリックメニュー
などなど。
# 設定について
ブラウザのテーマを変更できます。カスタムも出来ます。
ホームボタンを押した時に戻るサイトを選択できます。これは初期ホームとは異なります。ホームって言っていますが基本的にはデカいブックマークです。
検索エンジンを切り替えられます。google、bing、duckduckgo、yahoo!japan
ダウンロードされたアイテムの保存先を変更できます。
プライベートモードに変更可能です。
お気に入り(クイックリンク)機能があります
